# 部署與設定

## 架構

```
瀏覽器（React）── WebSocket ──> 對戰伺服器（Render，Node）── 引擎（同一份程式碼）
     │                                  │
     └── Firebase Auth（登入）          └── 驗證 Firebase 登入 token（只需要專案 ID，不需要機密金鑰）
```

- **對戰在伺服器的記憶體裡進行**，不逐步讀寫資料庫。伺服器收到操作 → 呼叫引擎 → 依每個人的權限過濾 → 廣播。
- **Firebase 只負責登入**（之後加上牌組儲存），用免費方案，不需要綁信用卡、不需要 Blaze。
- 房間存在伺服器記憶體。伺服器重啟或休眠後，進行中的牌局會消失。**這是目前還沒做完的地方**：之後會把「種子＋雙方牌組＋所有操作」存起來，重啟後用引擎重播還原。

## 在自己電腦上跑（開發）

兩個終端機各跑一個：

```bash
npm run dev --workspace @ws/server
```

```bash
npm run dev --workspace @ws/client
```

打開 http://localhost:5173 。沒有設定 Firebase 時是「測試登入」：輸入名字就能進，**每個瀏覽器分頁是不同的玩家**，開兩個分頁就能自己對打；第三個分頁可以測觀戰。

Firebase 設定好之後，本機也會要求真的登入。想用「測試登入」開多個分頁自己對打時，另外開一組測試用的伺服器和前端（不影響正式設定）：

```bash
PORT=8788 FIREBASE_PROJECT_ID= node packages/server/src/main.ts
```

```bash
npx vite --port 5174 --mode devlogin
```

第二行要在 `packages/client` 資料夾執行，並先建立 `packages/client/.env.devlogin.local`（內容：`VITE_FIREBASE_API_KEY=`、`VITE_FIREBASE_PROJECT_ID=`、`VITE_SERVER_URL=ws://localhost:8788`），然後打開 http://localhost:5174 。

手機測試：手機和電腦連同一個 Wi-Fi，用 `http://<電腦的區域網路 IP>:5173` 開網頁，伺服器網址會自動用同一個主機名稱。

## 設定 Firebase 登入（要你自己在網站上做）

1. 到 https://console.firebase.google.com 建立專案（不需要開 Google Analytics）。
2. 左側 **Authentication** → 開始使用 → **登入方式**，啟用：
   - **電子郵件／密碼**
   - **Google**（需要填一個支援電子郵件）
3. **專案設定**（齒輪）→ 一般 → 您的應用程式 → 新增 **網頁應用程式**（`</>`），取得 `firebaseConfig`。
4. 在 `packages/client/` 建立 `.env.local`（這個檔案不會進版本庫），填入：
   ```
   VITE_FIREBASE_API_KEY=...
   VITE_FIREBASE_AUTH_DOMAIN=...
   VITE_FIREBASE_PROJECT_ID=...
   VITE_FIREBASE_APP_ID=...
   ```
   這些都是公開的網頁設定，不是密碼。
5. 伺服器要知道專案 ID，才會改成要求 Firebase 登入：
   ```
   FIREBASE_PROJECT_ID=<同一個專案 ID>
   ```
6. Authentication → 設定 → **已授權的網域**：加入之後正式使用的網址（localhost 預設就有）。

設定完重開前端和伺服器，登入畫面就會從「測試登入」變成 Email 註冊／登入加 Google。

## 正式環境

- 前端：https://wsbattle-553dc.web.app （Firebase Hosting，連卡圖一起）
- 對戰伺服器：https://wsbattle.onrender.com （Render 免費方案，設定在 `render.yaml`）
- 程式碼：https://github.com/lukerker/wsbattle （私人；`cards/` 不上傳）

### 更新伺服器（規則、引擎、伺服器有改）

推到 GitHub 的 main，Render 會自動重新部署（約 3～5 分鐘）。**部署會重啟伺服器，進行中的牌局會消失**，挑沒人在玩的時候推。

```bash
git push origin master:main
```

### 更新前端（畫面、卡圖有改）

要在有 `cards/` 資料夾的這台電腦做，卡圖會在打包時一起放進去：

```bash
npm run build --workspace @ws/client
```

```bash
npx firebase-tools deploy --only hosting
```

改了 `firestore.rules`（例如新增牌組儲存）時，規則要另外部署，否則存牌組會被拒絕：

```bash
npx firebase-tools deploy --only firestore:rules
```

前端連哪個伺服器寫在 `packages/client/.env.production`。

### 注意

- Render 閒置 15 分鐘會休眠，第一個人打開網站要等約 1 分鐘，大廳會顯示「正在喚醒對戰伺服器…」。
- Firebase Hosting 免費額度：儲存 10 GB、每月流量 10 GB。整個網站約 5 MB，而且瀏覽器會快取。
- 卡圖的網址不需要登入就能打開；網址只給朋友，全站設定不讓搜尋引擎收錄。
