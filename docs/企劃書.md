# 黑白雙翼（WS）線上對戰模擬器 企劃書 v0.1

Oct 18, 2026 · @路可

## 專案概述

這是一款給朋友入坑用的網頁版黑白雙翼（Weiss Schwarz）線上對戰模擬器，免費、小圈子使用、手機也能玩。

現有的模擬器只有英文介面，對新手也不友善，所以我們自己做：繁體中文、階段提示清楚、每張卡都有白話的效果說明。

**目標**

- 住得遠的朋友，約好時間就能用房間代碼線上對戰
- 新手拿預組牌就能直接開打
- 7 個系列的全卡（預組加補充包）都能組牌
- 品質優先，不設死線

## 功能規格

功能圍繞一件事：約好時間的朋友，用一組代碼進同一個房間對戰，其他人可以一起看。

### 帳號與牌組

- 簡易註冊登入（Email 或 Google，待確認），牌組存在雲端
- 個人頁面：組牌、存檔、可存多副牌組
- 組牌時先選系列，只列出該系列的卡；檢查張數與同名卡上限等構築規則（以官方規則為準，見「風險與待確認事項」）
- 進房間時可選自己的牌組，或直接用該系列的預組

### 房間

- 建房時由伺服器產生 6 位數字代碼，並確保不重複
- 兩個對戰座位；座位坐滿後，其他人用同一組代碼進入就成為觀戰者
- 房間閒置一段時間後自動作廢（時間待定）
- 建房設定：時間限制、觀戰開關與人數上限

### 對戰

- 所有規則由伺服器判定，玩家端只送出操作
- 每個階段都提示現在可以做什麼；Encore、反擊階段等預設自動處理，進階玩家可切換手動
- 斷線重連：回到房間直接接回原局；對手斷線時畫面顯示連線狀態

### 觀戰

- 只看公開資訊：場上的卡、休息室、等級區、時計區、雙方手牌張數
- 動畫與對戰者看到的相同；中途加入直接顯示當前盤面
- 觀戰者唯讀，不能影響對局，也看不到任何一方的手牌

### 時間設定

建房時選擇，預設不限時。官方商店大會的對戰時間是一場 35 分鐘（[官方大會頁面](https://ws-tcg.com/events/5272/)），官方規定的是整場時間，沒有每次操作的倒數。

| 模式 | 說明 |
| --- | --- |
| 不限時（預設） | 無時間限制，適合休閒和新手 |
| 整場 35 分鐘 | 對應官方比賽的對戰時間；時間到的處理方式待確認 |
| 每次操作限時 | 每次操作倒數，秒數由建房者設定（範圍待定），是我們自己加的選項 |

## 介面與動畫設計

介面以手機橫向為主、電腦版放大，目標是新手一看就知道現在該做什麼，而且卡面再小也讀得到字。

### 卡面預覽

- 電腦：滑鼠移到卡上，左側顯示大圖、名稱、特徵與效果文字；效果用文字顯示，放大後一樣清楚
- 手機沒有滑鼠懸停，改成點一下卡片出現預覽與操作按鈕（出牌、橫置、取消）；長按只看不操作；預覽面板可收合
- 沒有卡圖時，用文字卡面自行排版：名稱、費用、力量、魂、觸發、效果
- 每張卡附白話的效果說明，沿用你「實戰拆解」的寫法
- 牌堆、休息室可點開查看內容，對手的也可以看

### 新手友善

1. 場地每一格都標示中文名稱，不用猜哪格是什麼區
2. 文字一律朝向自己，對手那側也一樣
3. 力量數字放在卡片下方的獨立標籤，不蓋在卡圖上
4. 手牌可展開或滑動，能看到完整卡面
5. 階段列顯示全部階段並標出目前位置，旁邊一句話說明「這時候你可以做什麼」
6. 進階選項預設全部自動，進階玩家才手動

### 動畫

- 翻牌：沿 Y 軸 3D 旋轉
- 橫置：旋轉 90 度；倒置：旋轉 180 度
- 抽牌、移動、傷害：位移加淡入淡出
- 只用 transform 和 opacity，手機上才不會卡
- 動畫由規則引擎輸出的事件列表驅動，規則和動畫完全分開

### 視覺風格

簡潔扁平的介面，場地背景用淺色桌墊質感，每個系列有一個主題色點綴。手機好讀為先，也保留一點系列特色。

## 技術架構

&#91;embedded content: 架構圖 · 玩家端、雲端函式、資料庫\]

每次操作都由雲端函式驗證並算出新狀態，結果寫入 Firestore，玩家端再即時收到各自看得到的部分；觀戰者只讀公開盤面。

**技術選擇**

- 語言：TypeScript，前端、規則引擎、雲端函式共用同一套程式碼
- 專案結構：engine（規則引擎）、functions（雲端函式）、client（網頁）三個套件
- 畫面：React＋Vite；動畫用 CSS 3D 轉換搭配動畫函式庫
- 資料庫分工：Firestore 存主要資料，[按讀寫次數計費](https://dev.to/sherry_walker_bba406fb339/cost-optimization-strategies-for-large-firebase-projects-ljp)；Realtime Database 只做上線與離線偵測，按頻寬與儲存計費
- 之後若需要更即時的計時或大量觀戰，再把對戰搬到 WebSocket 伺服器（例如 Cloud Run），引擎不用改

## 規則引擎與效果系統

規則引擎是整個專案最大的工作量，也是最需要一開始就設計對的部分，因為之後改架構等於重寫。

### 引擎的基本設計

- **純函式**：輸入「目前狀態＋一個操作」，輸出「新狀態＋事件列表」，亂數用固定種子。重播、寫測試、斷線重連都因此幾乎不用額外成本
- **獨立套件**：引擎不綁任何平台，目前跑在 Firebase 的雲端函式，之後要換成其他伺服器也不用改引擎
- **事件列表**：每次操作會輸出像「某張卡從手牌移到舞台」「某張卡橫置」的事件，畫面照事件播放動畫

### 效果資料化

每張卡的效果寫成「時機＋條件＋費用＋動作」的資料。動作由基本積木組成，例如抽牌、放入休息室、移動、加力量。大多數卡用模板就能表達，特殊的卡才寫獨立腳本。

### 待決選擇

效果執行到需要玩家選擇時，引擎暫停，進入「等待某位玩家回應」的狀態。多個效果同時觸發時的排序、對手能不能介入，都透過這個機制處理。

### 規則依據

引擎以官方總合規則為準，目前最新版是 ver. 1.111（2026 年 5 月 19 日更新，[官方 PDF](https://ws-tcg.com/wordpress/wp-content/uploads/2026/05/19125324/WS_rule_1.111.pdf)）。規則會更新，所以卡片資料要記錄對照的是哪個規則版本，更新時才知道哪些卡需要重新核對。

### 效果結算順序

同時誘發的自動能力先進入「待機」狀態，由回合玩家先決定順序，再換非回合玩家。升級、重洗牌等規則處理，一律先於自動能力。每解決完一個效果，就回到規則處理重新檢查一次（依官方總合規則第 8.5 節）。引擎直接照這個流程寫，不自己發明順序。

### 戰力計算

戰力不存成一個數字，每次要用時才現場計算：基礎力量加上所有目前有效的加成。

- **持續型（【永】）**：不儲存，計算時依場上現況即時算。例如每有一個其他リコリコ或武器角色就 +1000，角色離場，加成自動消失
- **指定型（那個回合）**：發動時選好目標，存成一筆加成，記錄對象、數值和結束時間。對象是那張牌本身，不是格子位置；回合結束時移除，牌離開舞台就作廢
- **發動當下定值型**：效果寫「X 是……的數量」時，X 在結算當下算好，之後不再變。各種寫法的結算時機對照官方規則確認
- **指定「哪些牌」**：用目標選擇器表達，例如己方全部角色、具有某特徵的角色、這張卡前面的角色、玩家自選 1 個；需要玩家選的，走「待決選擇」
- 少數把力量直接設為固定值的卡，加一層「先設定、再加減」
- 每種加成都寫情境測試：擺好場面、發動效果、檢查最終力量，戰鬥也用算出來的力量

### 可選擇的費用

「可以支付費用，支付了的話……」的效果，拆成四步：

1. 時機到時，引擎先檢查付不付得起；付不起就略過，不打擾玩家
2. 付得起，引擎暫停，問玩家要不要發動
3. 選發動後，若費用需要選牌（例如選哪張手牌），再問一次
4. 費用付完才結算後面的效果；不付，整段結束

這類任意效果如果錯過時機，視為略過（[說明](https://note.com/asonatu/n/na3542f1720b9)）。

畫面用底部彈出視窗，內容是卡名與縮圖、白話效果說明、費用，以及「支付並發動」「不發動」兩個按鈕。選了發動後，可選的牌亮起，點選後按確認；取消可回上一步。

- 對手畫面顯示「對手正在決定是否發動」；放入休息室的牌是公開的，對手和觀戰者都會看到動畫
- 有時間限制的房間，時間到沒回應就視為不發動
- 進階玩家可在設定中把常用選項改成自動，新手預設每次都問

### 隱藏資訊

手牌、牌庫內容只存在伺服器端，傳給每位玩家的資料已經過濾；觀戰者拿到的是只含公開資訊的版本。

### 測試

每張卡至少一個情境測試，確認效果和原文一致。卡池變大時，改引擎也不怕改壞已經完成的卡。

### 容易漏掉的效果細節

以下是目前想到、還需要在設計時處理的事項。

| 項目 | 要處理的重點 |
| --- | --- |
| 觸發圖示 | 魂、書（回收角色）、門（回收名場面）等，每種都是一個小效果，要列進效果模板 |
| 關鍵字能力 | 再演、助太刀、應援、集中、絆等，做成模板，卡片只填參數 |
| 能力賦予 | 例如「給予再演的能力」，要記錄誰得到、持續到何時 |
| 「不能」類限制 | 例如反轉後不能使用再演；和「可以」類效果衝突時的優先關係，對照官方規則 |
| 指定卡名的聯動 | 名場面聯動要求名場面區有指定卡名的卡，卡名要能精確比對 |
| 公開與看牌 | 「看」只有自己知道，「公開」或「展示」對手和觀戰者也看得到 |
| 每回合限制 | 記錄「本回合已發動」，回合結束時清掉 |
| 取消與悔棋 | 只允許在尚未確定的選擇階段取消；不做整局悔棋，因為有洗牌和隱藏資訊 |
| 重播與除錯 | 每局存下亂數種子和操作列表，出 bug 時能原樣重現 |
| 未完成的卡 | 卡片標記翻譯、程式化、測試的進度，沒通過的卡在組牌器灰掉 |
| 無窮迴圈 | 設定結算次數上限，超過就中止並提示 |

## 卡池與內容製作流程

7 個系列各自做到「預組加補充包全卡」，每張卡都要經過翻譯、程式化、測試三關才算完成。

### 7 個系列

1. BanG Dream（MyGO × Ave Mujica 彈）
2. Girls Band Cry
3. 莉可麗絲
4. 鏈鋸人
5. 孤獨搖滾
6. NIKKE
7. 碧藍幻想

### 每張卡的製作流程

1. 你提供日文卡面圖片
2. 我讀出日文效果，翻成繁體中文，並寫成效果資料
3. 原文、中文、程式化結果三欄並排，由你快速核對（日文圖片是我讀字，偶爾會有誤讀）
4. 寫情境測試，確認效果和原文一致
5. 完成的卡才進入卡池

同一張卡的不同稀有度（普通版、閃卡版等）只是不同的圖，效果相同，用同一個基礎編號處理，不用重做。

### 預組牌

- 預組是官方固定的 50 張牌組，各系列的預組內容固定
- 預組內每種卡的張數需要另外確認；以莉可麗絲預組為例，不同卡面有 20 種，若每種只有 2 或 4 張，剛好是 5 種 4 張、15 種 2 張，但哪幾種是 4 張要等你整理的牌表
- 驗算標準：合計剛好 50 張，同名卡不超過 4 張，名場面卡不超過 8 張
- 預組牌存成固定牌表的資料檔，內容可以之後再補，不影響引擎和其他功能
- 沒有預組的系列，我會用補充包的卡配一副入門推薦牌組，讓新朋友也能直接上手

### 完成標準

一個系列的預組完成後，該系列就能用預組對戰；補充包全卡完成後，才開放該系列的自由組牌。

## 版權與使用範圍

本專案只給你和朋友在小圈子內使用，並且把卡圖設計成可替換，讓版權風險集中在圖片這一塊。

- 不商用、免費不等於沒有版權問題；卡圖、卡名、角色形象屬於版權方，這個風險是存在的，我不是律師，細節請以專業意見為準
- 我查過 Bushiroad 的二次創作規範，沒有找到針對 WS 數位化的明確條款，官方立場以官方網站為準
- 程式只存卡號和效果資料，卡圖是獨立欄位，可以用文字卡面，或讓玩家自己上傳圖片，或私下放圖
- 不把官方卡圖放在公開網址上，也不開放陌生人註冊，降低被注意到的機會
- 規則本身（回合流程、階段、效果邏輯）一般不受著作權保護，風險主要在卡圖、卡名和角色形象
