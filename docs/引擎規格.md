# 規則引擎規格（依官方總合規則 ver.1.113）

> 來源：ヴァイスシュヴァルツ 総合ルール ver.1.113（2026/10/15 更新），官方規則頁 https://ws-tcg.com/rules/
> 每一條後面的〔 〕是規則編號，實作和測試時對照用。用語依本專案：クライマックス＝名場面、ストック＝能量、クロック＝傷害區、控え室＝休息室、思い出＝回憶區。

## 0. 大原則

- 卡片文字和規則衝突時，以卡片文字為準〔1.3.1〕
- 做不到的事就不做；只做得到一部分就盡量做〔1.3.2〕。已經是某狀態的卡，不會「再變成」那個狀態〔1.3.2.1〕
- 「可以做」和「禁止做」同時存在時，禁止優先〔1.3.3〕
- 雙方要同時選擇時，回合玩家先選，非回合玩家看到結果後再選〔1.3.4〕
- 選數字時只能選 0 以上的整數〔1.3.5〕

## 1. 勝負

- 等級區有 4 張以上 → 敗北〔1.2.2.1〕
- 牌組和休息室都沒有卡 → 敗北〔1.2.2.2〕
- 以上兩項在「規則處理」時才判定〔1.2.2、9.4〕；雙方同時敗北為平手〔1.2.3〕
- 任何時候都可以投降，立即敗北〔1.2.4〕

## 2. 領域與公開資訊

| 領域 | 公開？ | 重點 |
|---|---|---|
| 牌組 | 非公開 | 誰都不能看內容或改順序〔3.2.2〕 |
| 手牌 | 非公開 | 自己可看、可自由排序；上限 7 張（結束階段檢查）〔3.3〕 |
| 休息室 | **公開** | 雙方都可以自由查看內容〔3.4.2〕；新放的卡疊在最上面 |
| 舞台（5 格） | 公開 | 前列左、中、右；後列左、右〔3.6.4〕 |
| 傷害區 | 公開 | 不能改順序；7 張以上觸發升級〔3.8〕 |
| 等級區 | 公開（裏向き的卡例外） | 4 張以上敗北〔3.9〕 |
| 能量區 | 非公開 | 裏向き；拿取時從最上面〔3.10.2〕 |
| 名場面區 | 公開 | 原則上只有 1 張〔3.11〕 |
| 回憶區 | 公開（裏向き的卡例外） | 〔3.12〕 |
| 解決領域 | 公開 | 判定卡、傷害翻開的卡、事件卡、集中翻開的卡暫放這裡〔3.13〕 |
| 標記區 | 非公開 | 每格對應一個；目前兩副預組用不到〔3.7〕 |

- 每個領域的**張數**雙方隨時都能看〔3.1.2〕
- 卡從舞台移到其他領域，視為新的一張卡，原本的效果不會跟著〔3.1.4〕
- 格子的位置關係〔3.6.5、3.6.6〕：
  - 「前」：後列左 → 前列左、前列中；後列右 → 前列中、前列右
  - 「正面」：我方前列左 ↔ 對手前列右；中 ↔ 中；右 ↔ 左

## 3. 卡片狀態

- 直立（スタンド）、橫置（レスト）、倒置（リバース）〔4.6.1〕
- 從格子以外放到格子時，一律直立〔3.6.3〕；格子之間移動不改變狀態

## 4. 遊戲準備〔5〕

1. 牌組 50 張整；同名卡最多 4 張；名場面合計最多 8 張〔5.1.2〕
2. 洗牌後放成牌組；隨機決定先攻（不可讓一方自選）〔5.2.1.3〕
3. 各抽 5 張；先攻先，每人一次，把任意張數的手牌放進休息室，再抽同樣張數（換牌）〔5.2.1.4〕
4. 先攻玩家的回合開始

## 5. 回合流程〔6〕

每個階段開始時，先觸發「～的始めに」的自動能力，再進入檢查時點。

| 階段 | 做什麼 |
|---|---|
| 起立〔6.2〕 | 自己舞台的角色全部直立 |
| 抽牌〔6.3〕 | 抽 1 張 |
| 時計〔6.4〕 | 可以選 1 張手牌放到傷害區，放了就抽 2 張（可略過） |
| 主要〔6.5〕 | 可重複做：打出角色（指定格子）、打出事件、使用起動能力、交換兩格的卡〔6.5.1.2.4〕；選擇不做事就進入下一階段 |
| 名場面〔6.6〕 | 只能打出 1 張名場面，或不打 |
| 攻擊〔6.7、7〕 | 見第 6 節 |
| 結束〔6.8〕 | 觸發「回合結束時」→ 手牌超過上限要丟到上限 → 名場面區的卡放進休息室 → 檢查時點 → 「那個回合中」的效果全部消失 → 換對手 |

## 6. 攻擊與戰鬥〔7〕

一次攻擊（攻擊子階段）依序是：宣告 → 判定 → 反擊（只有正打）→ 傷害 → 戰鬥（只有正打）。全部攻擊結束後進入安可步驟。

### 6.1 宣告攻擊〔7.2〕
- 只能用自己前列、直立的角色〔7.2.1.3.1.1〕
- **先攻玩家的第 1 回合只能攻擊 1 次**〔7.2.1.3.1.2〕
- 攻擊方式：
  - 正面沒有對手角色 → 自動變成**直接攻擊**，該回合魂傷 +1〔7.2.1.4.1〕
  - 正面有角色 → 選**正打**（フロントアタック）或**側打**（サイドアタック）〔7.2.1.4.2〕
  - 側打時，該回合魂傷 −（正面角色的等級）
- 宣告後攻擊角色橫置〔7.2.1.5.3〕；攻擊方式選定後就不會改變〔7.2.1.4.3〕
- 正打時，正面的角色成為「防禦角色」，兩者互為「戰鬥對手」〔7.2.1.5.1〕

### 6.2 判定步驟〔7.3〕
- 牌組最上面 1 張翻到解決領域，執行它的判定圖示，然後**裏向き放進能量區**〔7.3.1.2〕
- 判定圖示〔4.14.2〕（兩副預組用到的打 ✔）：

| 圖示 | 效果 |
|---|---|
| ✔ 魂（ソウル） | 該回合攻擊角色魂傷 +1（強制） |
| ✔ 選擇（チョイス） | 可以從休息室選 1 張判定圖示有「魂」的角色，放進手牌或能量區 |
| ✔ 寶（トレジャー） | 這張卡回到手牌（強制），之後可以把牌組最上面 1 張放進能量區 |
| ✔ 歸（カムバック，門形圖示） | 可以從休息室選 1 張角色回到手牌 |
| 門（ゲート） | 可以從休息室選 1 張名場面回到手牌 |
| 其他 | 回手（リターン）、儲（プール）、抽（ドロー）、射（ショット）、待機（スタンバイ）、機會（チャンス）、發現（ディスカバリー）、聚焦（フォーカス） |

### 6.3 反擊步驟〔7.4〕（只有正打）
- 防守方可以使用**一次**帶反擊圖示的事件或起動能力，例如助太刀〔7.4.1.2〕

### 6.4 傷害步驟〔7.5〕
- 攻擊角色對對手造成等於魂傷的傷害；魂傷 0 以下就不造成傷害〔7.5.1.2〕
- 傷害處理〔4.12〕：一張一張翻牌組最上面的卡到解決領域
  - 翻到**名場面** → 這次翻出的卡全部放進休息室，傷害取消（キャンセル）
  - 翻滿 N 張都沒有名場面 → 依原順序放到傷害區最上面
- 側打或直接攻擊：傷害步驟後攻擊結束

### 6.5 戰鬥步驟〔7.6〕（只有正打）
- 比較攻擊力，較低的那方倒置；相同則雙方都倒置〔7.6.1.2〕
- 任一方已不在場上就不比較〔7.6.1.3〕

### 6.6 安可步驟〔7.7〕
- 回合玩家先，把自己倒置的角色一張一張放進休息室（每放一張都有檢查時點）；接著非回合玩家；重複到雙方都沒有倒置角色〔7.7.1.2～7.7.1.4〕
- **所有角色預設都有「安可［③］」**：從舞台放進休息室時，可以付 3 能量，以橫置狀態回到原本的格子〔10.2.2、10.2.3〕。卡片上寫的安可是另一個能力，兩個都能選。

## 7. 出牌條件〔8.6.2〕

- **顏色條件**：要打出的卡，顏色必須和自己等級區或傷害區的某張卡相同〔8.6.2.1.1〕
  - Lv0 的角色和事件不需要滿足顏色條件〔8.6.2.1.1.1〕
  - 名場面**需要**滿足顏色條件（只有等級條件不看）
- **等級條件**：卡片等級 ≤ 自己等級區的張數〔8.6.2.1.2〕；名場面不看等級〔8.6.2.1.2.1〕
- **費用**：從能量區把等於費用張數的卡放進休息室〔2.7.2〕；丸數字 ①② 同理〔8.4.3〕
- 打出角色時指定格子；已有角色的話，舊角色在下一次規則處理時進休息室〔8.6.2.5.1〕
- 事件：放到解決領域，執行效果後放進休息室〔8.6.2.5.2〕

## 8. 費用〔8.4〕

- 有多個費用時，從前面依序支付；**支付期間不做重洗和升級**〔8.4.2.1、9.2.3、9.3.3〕
- 只要有一部分付不起，就完全不能付〔8.4.2.2〕
- 自動能力的 [費用]：解決時可以選擇付或不付〔8.1.1.2.2〕；不付也算「已使用」〔8.7.3.2.1〕

## 9. 檢查時點與自動能力〔8.5、8.7〕

檢查時點的順序（引擎直接照這個寫）：
1. 執行所有規則處理；做完若又產生新的規則處理，重複〔8.5.1.1〕
2. 回合玩家有待機中的自動能力 → 選 1 個執行，回到 1〔8.5.1.2〕
3. 非回合玩家有待機中的自動能力 → 選 1 個執行，回到 1〔8.5.1.3〕
4. 結束

- 誘發條件滿足 → 自動能力進入「待機」；滿足幾次就待機幾次〔8.7.2〕
- 待機的自動能力**必須**執行（但可以選順序）〔8.7.3.1〕
- 「每回合 N 次」的能力達到次數後就不能再用〔10.19.3〕
- 從舞台離開而誘發的能力，用離開前在舞台上的資訊〔8.7.4.1.2〕
- 能力的卡已經移到別的領域，仍要執行，做不到的部分就失敗〔8.7.7〕

**遊玩時點**：任何玩家要取得行動機會前，一定先跑一次檢查時點〔4.5.2〕。

## 10. 規則處理〔9〕

| 處理 | 類型 | 內容 |
|---|---|---|
| 重洗〔9.2〕 | 插入型（立刻） | 牌組沒有卡 → 休息室全部洗回牌組，然後把牌組最上面 1 張放到傷害區（重洗懲罰）。在傷害處理中且休息室也空、解決領域沒有名場面 → 敗北〔9.2.2.1〕 |
| 升級〔9.3〕 | 插入型 | 傷害區 7 張以上 → 從最下面 7 張選 1 張放到等級區，其餘 6 張放進休息室 |
| 敗北判定〔9.4〕 | 檢查型 | 見第 1 節 |
| 攻擊力不足〔9.5〕 | 檢查型 | 攻擊力 0 以下的角色放進休息室 |
| 不正卡〔9.6〕 | 檢查型 | 格子裡不是角色、名場面區不是名場面 → 休息室；同一格有多張 → 只留最後放的 |

- 插入型：條件一成立就中斷目前的動作立刻處理〔9.1.2.1〕；雙方都有時回合玩家先〔9.1.2.1.1.1〕
- 檢查型：只在檢查時點確認〔9.1.2.2〕

## 11. 持續效果的計算順序〔8.9〕

1. 卡片上印的數值為基準〔8.9.1.1〕
2. 先套用「不改攻擊力、魂傷」的持續效果（例如給予能力、給予特徵）〔8.9.1.2〕
3. 再套用改攻擊力、魂傷的持續效果〔8.9.1.3〕
4. 互相依賴時，被依賴的先算〔8.9.1.4〕；其他依發生順序〔8.9.1.5〕
- **非【永】的持續效果，不會套用到之後才進場的卡**〔8.9.2〕。例：「你的角色全部，那個回合中 +1000」的事件，對之後才打出的角色無效。【永】（例如名場面的效果）則會套用到新進場的角色。

## 12. 關鍵字

| 關鍵字 | 規則 | 意思 |
|---|---|---|
| 應援 | 〔10.3〕 | 只有在**後列**時有效 |
| 絆 | 〔10.4〕 | 從手牌放到舞台時，可付費從休息室撿回指定卡名的卡 |
| 助太刀 | 〔10.5〕 | 只能在對手的反擊步驟、自己等級 ≥ Y 時使用；「使用了助太刀」＝付完費用 |
| 安可 | 〔10.2〕 | 見 6.6 |
| 集中 | 〔10.7〕 | 翻開的卡先放到解決領域，再一起放進休息室 |
| CX 連動圖示 | 〔8.12〕 | 規則上沒有意義，條件寫在文字裡 |

## 13. 其他

- 無限循環：雙方都停不下來 → 平手〔11.1〕；引擎另設結算次數上限，超過就中止並提示
- 判定卡在放到解決領域之後才增減的圖示不算〔7.3.1.2.2〕
